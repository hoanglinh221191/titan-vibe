Records of checks run on this package's titan.exe. HELDOUT480_REPLAY.json replays the 480 held-out inputs against the reference outputs of this release (examples/heldout480/manifest.json); the 1.0.2 references are kept in manifest_v1.0.2.json, and SOURCE_AUDIT.json lists how many references changed (search-route names and one PDB rounding digit). FIRST_FRAME5_REPLAY.json and REAL367_REPLAY.json replay the first frame and all 367 comparison frames of the five molecular systems, including the two Figure 1 frames, against the outputs deposited on 11 September 2026, comparing atom records at PDB precision and the scientific report fields. Two quantities are counted separately rather than compared: the search-route name, and the input checksum (wrapped_coordinate_hash). Release 1.0.3 builds the lattice vectors of general triclinic cells exactly, which changes the last binary digits of the cell matrix in 2 of the 31 peptide-pair frames and therefore their input checksum; their reconstructed coordinates are identical. These records establish implementation agreement at the stated precision, not independent physical truth.
